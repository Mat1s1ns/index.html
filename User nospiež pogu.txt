1. Dzinējs ielādējas
javascriptinitSqlJs({ locateFile: f => `https://cdnjs.cloudflare.com/ajax/libs/sql.js/1.10.2/${f}` })
Tas lejupielādē SQLite (kā WebAssembly) no interneta uz pārlūkprogrammu.

2. Datubāze tiek izveidota atmiņā
javascriptdb = new SQL.Database();
Šī ir "datubāze" — tā ir tikai mainīgais, kas atrodas operatīvajā atmiņā.

html<button onclick="addGramata()">Pievienot</button>

4. JS nolasa no db un ieraksta HTML tabulā
javascriptconst res = db.exec('SELECT * FROM Gramatas')

Savienojuma vieta ir db — tas ir globāls mainīgais, kuru koplieto gan HTML (caur onclick), gan visas JS funkcijas. Nav nekāda kabeļa, URL vai paroles — viss ir vienā failā, vienā cilnē, vienā mainīgajā.
